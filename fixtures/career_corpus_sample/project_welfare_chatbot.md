# 프로젝트: 공공기관 복지 상담 챗봇 (예시 더미 데이터)

지자체 산하 복지재단의 상담 챗봇 구축 프로젝트에서 PM 겸 개발자로 참여했다.
상담원의 반복 질의응답을 챗봇이 1차로 처리하도록 설계했고, 초기 도입 3개월 동안
상담원 1인당 처리 건수를 약 15% 늘리는 효과를 확인했다.

주요 역할:
- 상담 시나리오 설계 및 대화 흐름(FSM) 정의
- FastAPI + PostgreSQL 기반 백엔드 API 개발
- 현업 상담원 대상 요구사항 인터뷰 및 반복 개선

기술 스택: Python, FastAPI, PostgreSQL, Burr, Docker
